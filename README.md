# 我們這一屆，1980

從等卡通，到等爸媽回電話。八頁台灣世代回憶彩色漫畫，繁體中文手機閱讀版。

## 閱讀與部署

- 建置工具：不需要。`index.html` 可透過任意靜態 HTTP 伺服器閱讀。
- GitHub Pages：`main` 分支、`/ (root)` 目錄。
- 本機預覽：`python -m http.server 8000`，開啟 `http://localhost:8000`。
- `manifest.json` 保存章節標題、年代、旁白與圖檔資料；修改文字時也需同步 `index.html`。
- `reader.js` 只提供上一章／下一章、章節位置與閱讀進度。停用 JavaScript 仍可閱讀全文及使用章節連結。

## 圖片

- 公開版本只有 WebP，原始 PNG 不上傳到此 repository。
- 每頁提供完整寬度與 640 px 版本，使用 `srcset` 讓瀏覽器依螢幕及像素密度選取。
- 第一頁優先載入，後續章節 `loading="lazy"`。
- 另有固定寬高以減少版面位移；點擊圖像可開啟完整尺寸。
- 四格閱讀順序為左上、右上、左下、右下，編號旁白以 HTML 文字呈現。

## 內容說明

本作改編自使用者提供的〈我們這一屆，1980〉。阿陳是虛構的世代合成人物；人物、對話與場景是創作，不是個人傳記或訪談紀錄，也不代表所有台灣人的共同經驗。圖片由 AI 生成，器物、街景與服裝採藝術化重現，不作歷史考證依據。

年代與歷史事件僅提供故事背景，個人情節均為虛構。原文未另附公開來源，本 repository 不連結私人對話。

## 隱私與可及性

無追蹤器、外部字型、廣告、分析工具、Cookie 或本機儲存。提供 `lang="zh-Hant"`、語義化章節、文字旁白、圖片替代說明、鍵盤焦點、跳至內容連結及減少動畫偏好支援。
